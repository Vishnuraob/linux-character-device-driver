# Professional Linux Character Device Driver

A Linux Character Device Driver developed from scratch as an Embedded Linux learning and portfolio project.

## Objectives

- Understand Linux kernel modules
- Understand character device drivers
- Learn user-space/kernel-space communication
- Implement read/write operations
- Implement IOCTL
- Implement synchronization
- Learn Linux driver development practices
